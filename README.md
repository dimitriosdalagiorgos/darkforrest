# Σκοτεινό Δάσος

Επιτραπέζιο παιχνίδι για διαδραστικό πίνακα αφής, για τον Όμιλο **Future Worlds** (ΔΗΜ.Ω.Σ. Ημερήσιο ΓΕΛ Κοζάνης, 2026-2027).

Κάθε νησίδα της τάξης είναι ένας πολιτισμός σε έναν σκοτεινό γαλαξία. Σε κάθε γύρο γυρίζει μια κάρτα Γεγονότος, και οι πολιτισμοί μαντεύουν αν είναι επιστήμη, εύλογη υπόθεση ή μυθοπλασία. Μετά διαλέγουν μία κίνηση: ανάπτυξη, ακρόαση, σήμα, χτύπημα ή μετανάστευση. Στο τέλος αλλάζουν έναν κανόνα του σύμπαντος και ρωτούν: «Τι θα γινόταν αν…;».

- **Πίνακας:** ανοίξτε τη σελίδα στον browser του διαδραστικού.
- **Tablet νησίδων (προαιρετικά, ένα ανά νησίδα):** «Σύνδεση tablet (QR)» στην αρχική οθόνη. Η νησίδα διαλέγει πολιτισμό, κρύβεται, μαντεύει και παίζει από το tablet· οι απαντήσεις της ακρόασης και του κατασκόπου φαίνονται μόνο εκεί.
- **Κονσόλα του Σύμπαντος (προαιρετική):** «Σύνδεση κονσόλας (QR)» και σκανάρισμα με το κινητό του/της εκπαιδευτικού. Χωρίς κονσόλα το παιχνίδι παίζεται με post-it.

Εμπνευσμένο από τη θεωρία του «Σκοτεινού Δάσους» του Liu Cixin. Το παιχνίδι, οι κανόνες και οι κάρτες είναι πρωτότυπα.
